# MEHMET AUTO

> **“Otomobili sadece sürme. Keşfet.”**

MEHMET AUTO; otomobilleri derinlemesine keşfetmek, teknik özelliklerini incelemek, araçları yan yana karşılaştırmak ve otomotiv dünyasındaki son gelişmeleri takip etmek için geliştirilmiş modern, yüksek performanslı ve tam teşekküllü bir otomobil platformudur.

---

## 🌟 Öne Çıkan Özellikler

1. **Gelişmiş Filtreleme & Canlı Arama:**
   - Marka, Model adı, Kasa tipi (SUV, Sedan, Spor vb.), Yakıt türü (Benzin, Hibrit, Elektrik) ve Bütçe aralığı ile anında filtreleme.
2. **Kapsamlı Araç Kataloğu & Detay Modalı:**
   - 12+ detaylı süperspor, elektrikli ve lüks otomobil.
   - Her araç için motor ünitesi, beygir gücü (HP), tork (Nm), 0-100 km/s hızlanma, son hız, yakıt tüketimi, bagaj kapasitesi ve donanım maddeleri.
3. **Dinamik Araç Karşılaştırma Aracı (VS):**
   - Açılır kutulardan seçilen iki aracı tüm teknik parametreleriyle yan yana kıyaslama. Üstün olan teknik değerlerin anlık otomatik vurgulanması.
4. **Elektrikli Gelecek Bölümü:**
   - WLTP Menzil (km), Batarya Kapasitesi (kWh), Hızlı Şarj Süresi ve Elektrik Gücü (kW) göstergeleri.
5. **Haftanın Otomobili:**
   - Haftanın seçilen modeline özel devasa görsel ve performans paneli.
6. **Favori Yönetim Sistemi:**
   - Tarayıcının `localStorage` hafızasında saklanan ve navbar üzerinden yönetilebilen favori araçlar listesi.
7. **Otomobil Haberleri & Okuma Modalı:**
   - Katı hal bataryaları, hibrit V8 üniteler, otonom sürüş seviyeleri üzerine güncel haber içerikleri.
8. **İletişim & Form Doğrulama:**
   - Eksiksiz doğrulama kuralları ve şık geri bildirim ekranı.
9. **%100 Responsive & Modern Koyu Tema:**
   - Mobil, tablet ve masaüstü cihazlarla kusursuz uyumlu, cam (glassmorphism) efektli koyu tasarım.

---

## 🚀 Kullanılan Teknolojiler

- **Frontend:** React 19 + TypeScript + Vite
- **Stil & Tasarım:** Tailwind CSS v3
- **İkonlar:** Lucide React
- **Durum Yönetimi:** React Hooks & Web Storage API (LocalStorage)
- **Dağıtım:** Vercel & GitHub

---

## 💻 Yerel Geliştirme (Local Setup)

Projeyi bilgisayarınızda çalıştırmak için:

```bash
# Bağımlılıkları yükleyin
npm install

# Geliştirme sunucusunu başlatın
npm run dev

# Üretim (Production) derlemesi alın
npm run build

# Canlı derlemeyi yerelde önizleyin
npm run preview
```
